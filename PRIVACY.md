# Kebijakan Privasi Asisten Bayi

Berlaku sejak 8 November 2026.

Asisten Bayi adalah aplikasi informasi kesehatan bayi dan anak untuk orang tua dan pengasuh dewasa. Kebijakan ini menjelaskan data apa yang ada di aplikasi, di mana disimpan, dan pihak lain yang terlibat.

## Data yang Anda masukkan

- **Profil anak** (nama panggilan opsional dan tanggal lahir), **jawaban cek gejala**, dan **centang perkembangan** hanya disimpan di penyimpanan lokal perangkat Anda.
- Aplikasi tidak memiliki akun, tidak memiliki server sendiri, dan tidak mengirim data tersebut ke pengembang atau pihak lain.
- Menghapus data aplikasi atau mencopot pemasangan menghapus seluruh data ini dari perangkat.

## Pembaruan data pengetahuan

Aplikasi Android memeriksa file data terbaru (`kb.json`) dari GitHub setiap kali dibuka. Permintaan ini hanya mengunduh file data; tidak ada data anak atau jawaban Anda yang dikirim. Seperti setiap permintaan internet, GitHub dapat mencatat alamat IP dan informasi teknis perangkat sesuai [kebijakan privasi GitHub](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement).

## Iklan (Google AdMob)

Aplikasi Android menampilkan iklan banner dari Google AdMob **hanya** di layar panduan, perkembangan, imunisasi, dan menu Lainnya. Iklan tidak pernah ditampilkan di beranda, cek gejala, hitung napas, atau keamanan obat.

Google dapat mengumpulkan dan memakai ID iklan perangkat, alamat IP, dan informasi perangkat untuk menampilkan, mengukur, dan mencegah penyalahgunaan iklan. Penjelasan lengkap: [Cara Google menggunakan informasi dari situs atau aplikasi yang menggunakan layanannya](https://policies.google.com/technologies/partner-sites). Anda dapat menyetel ulang atau menghapus ID iklan di pengaturan Android (Privasi → Iklan).

## Pembayaran sukarela

Tombol "Traktir kopi" memakai Google Play Billing. Pembayaran sepenuhnya diproses oleh Google; pengembang tidak menerima nomor kartu atau data pembayaran Anda. Pembayaran ini tidak membuka fitur apa pun.

## Versi online dan fitur Tanya

Versi online berjalan di claude.ai. Pertanyaan yang Anda kirim lewat fitur Tanya diproses oleh Claude (Anthropic) sesuai [kebijakan privasi Anthropic](https://www.anthropic.com/legal/privacy). Aplikasi Android dan versi offline tidak memiliki fitur Tanya.

## Anak-anak

Aplikasi ini ditujukan untuk orang dewasa (orang tua dan pengasuh), bukan untuk digunakan oleh anak.

## Hak Anda

Karena data Anda hanya ada di perangkat Anda, Anda dapat melihat, mengubah, atau menghapusnya kapan saja langsung di aplikasi (menu Profil anak) atau dengan menghapus data aplikasi. Kebijakan ini disusun dengan memperhatikan Undang-Undang Nomor 27 Tahun 2022 tentang Pelindungan Data Pribadi.

## Batasan aplikasi

Asisten Bayi bukan alat diagnosis dan bukan pengganti pemeriksaan dokter, bidan, atau tenaga kesehatan. Dalam keadaan darurat, segera ke IGD atau fasilitas kesehatan terdekat.
